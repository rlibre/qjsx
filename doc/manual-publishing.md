# Publishing the JS developer manual

The manual of the JS developer (`doc/jsmanual/`, Astro + Starlight + starlight-typedoc) is
published on GitHub Pages at **https://rlibre.github.io/qjsx/** by the workflow
`.github/workflows/manual.yml`.

## When it runs

- on a push to `main` that changes `doc/jsmanual/**`, any `*.d.ts` file (the API reference
  is generated from the typings next to the modules, anywhere in the repository) or the
  workflow itself;
- by hand: GitHub, tab Actions, workflow "Manual", "Run workflow".

Two jobs: `build` (checkout of the whole repository, Node 26, `npm ci`, `npm run build` in
`doc/jsmanual`, upload of `dist/`) then `deploy` (publication in the `github-pages`
environment). One publication at a time; a running one is never cancelled.

## Base path and links

The site is a project page, served under `/qjsx/`: `astro.config.mjs` sets
`site: 'https://rlibre.github.io'` and `base: '/qjsx'`. The base is the same locally: the
dev server (`npm run dev`) serves the manual at http://localhost:4321/qjsx/.

Astro does not add the base to links written by hand, so **links in the pages are
relative**:

- between guides: `[The project file](../project/)`, not `(/guides/project/)`;
- in the front matter of `index.mdx` (hero actions): `guides/getting-started/`.

A link that ignores the base is broken locally too, so clicking through `npm run dev` shows
it. The API reference generated by starlight-typedoc takes the base into account by itself.

## Settings of the repository (once, by hand)

GitHub, repository settings, Pages, "Build and deployment": **Source = GitHub Actions**. The
first run creates the `github-pages` environment.

## Updating the actions

The actions are pinned by commit SHA, the version in a comment
(`actions/checkout@<sha> # v7.0.1`): a tag can be moved, a SHA cannot. To update one: take
the new release of the action, check its notes and the security advisories of its
repository, then replace both the SHA and the comment. Versions checked on 2026-11-16:
`actions/checkout` v7.0.1, `actions/setup-node` v7.1.0, `actions/upload-pages-artifact`
v5.0.0, `actions/deploy-pages` v5.0.1.

The npm dependencies are the versions of `doc/jsmanual/package-lock.json` (`npm ci`).
